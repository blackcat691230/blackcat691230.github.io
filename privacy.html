LINE Agent AI 隱私權政策

最後更新日期：2026 年 11 月 5 日

一、服務介紹

LINE Agent AI 是透過 LINE 提供的個人 AI 助理， 包含智慧問答、行程管理、提醒通知及 Google Calendar 行事曆整合功能。

二、蒐集及處理的資料

為提供服務，本系統可能處理以下資訊：

  • LINE 使用者識別碼
  • 使用者傳送的訊息與指令
  • 行程名稱、日期、時間及提醒設定
  • Google Calendar OAuth 授權資訊
  • 使用者授權存取的日曆活動資料

三、資料使用目的

上述資料僅用於提供 AI 回覆、 建立及管理行程、發送提醒通知， 以及執行使用者要求的 Google Calendar 操作。

四、Google Calendar 資料使用

本服務僅在使用者授權後， 依授權範圍存取 Google Calendar 資料。 日曆資料用於使用者要求的行程建立、 更新、查詢或管理功能。

本服務不會將 Google 使用者資料出售， 亦不會將 Google Calendar 資料用於廣告用途。 Google 使用者資料的使用遵循 Google API Services User Data Policy， 包括 Limited Use 規定。

五、資料儲存與安全

本服務使用 Google Cloud 基礎設施， 包含 Cloud Run 與 Firestore。 不同 LINE 使用者的行程資料採獨立管理。 Google OAuth 授權憑證以加密方式儲存， 並透過存取控制降低未經授權存取的風險。

六、第三方服務

本服務可能使用 LINE、Google Calendar、 Google Cloud 及 Google Gemini API 處理提供功能所需的資料。 各服務的資料處理方式亦受其各自的 隱私權政策約束。

七、資料保留與刪除

行程及相關授權資料會依提供服務所需的期間保留。 使用者可以透過下方聯絡信箱提出 查詢、更正或刪除個人資料的要求。 收到要求後，管理者將確認身分， 並依適用法規及實際系統能力處理。

八、撤銷 Google 授權

使用者可隨時前往 Google 帳戶第三方連結設定 撤銷 LINE Agent AI 的 Google 存取權。 撤銷授權不代表已儲存於本服務的資料 會自動刪除；如需刪除，請聯絡管理者。

九、政策變更

本政策可能隨服務功能或法規要求更新， 最新版本將公布於本頁面。
